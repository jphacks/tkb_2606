## しょうたろう側との接続
既存の保存・来歴・入力審査APIは変更していません。解析器を重複実装していません。
`Cartowords.MapPresentation` は描画専用DTOです。解析側の正式な型を置き換えるものではなく、アダプターで変換してください。

1. CartographEditorView.MapRefreshRequested を購読。確定編集後500msで MapRequest が届きます。
2. その時点のプロジェクト・本文・来歴を取得して解析し、全ノート分の MapSnapshot を作ります。
3. snapshot.Request には届いた request をそのまま渡し、view.PresentMap(snapshot) を呼びます。
4. ProjectKey、Generation、NoteRevisions が古い結果はUI側で破棄します。異なるプロジェクトの結果も破棄します。

MapNode.File は既存 DocumentRecord.id と同じ拡張子なし相対パス（例：大学/生物）。Line は1始まり、TypedChars は来歴から解析側が算出した直接入力文字数です。見出しIDは全ノートを通じて一意にしてください。
MapRoad は From/To に描画ノードIDを指定。MapFog/MapMark/MapFlower も存在するノードを参照します。存在しないリンク先は架空ノードにせず、対応する注意マークへ変換してください。
未ロードのノートは既存workspaceのrevisionが0の場合があります。requestのバージョン集合を独自の番号で置き換えないでください。解析のためにロードしてバージョンが変わった場合は、新しいリクエストの結果を公開してください。
購読は初期画面更新前に行ってください。未接続時の通常画面は「解析データ待ち」です。「表示サンプル」は明示した架空データで、実ノートは開きません。

(この記述は古くなりました。花の色変更の UI と SetFlowerColor は、花が感情ごとの色付きドット絵になったため、M5 で削除しました。)
