# プロジェクト開閉・マップ表示の再確認

- 起動時、前回のパスを「開いている」ように入力欄へ表示する処理を削除。未選択時は欄を空にして「ファイルが選択されていません」と表示します。前回の場所はフォルダ選択ダイアログの初期位置にだけ使います。
- Bridge.ProjectRootを公開し、実際に開いたプロジェクトを表示の基準にしました。保存先の入力と、実際に開いた状態をステータスで区別します。
- フォルダ選択のキャンセルでは変更せず、開く処理が成功した後にパス表示を確定。失敗時は実際のパスへ戻してノート一覧も更新し、エラーを表示します。
- 「閉じる」成功時にパスを空にし、本文・一覧・マップを未選択へ戻します。保存失敗時は閉じずにエラーを表示。IME変換や入力の審査で操作を止めた際も案内を表示します。
- プロジェクトを開いている間はサンプルボタンを隠し、実ノートの地図を表示。サンプルを見ていた場合も実ノートへ戻します。
- マップの線を太く・明るく調整。実際の線数を表示し、線がない場合は関連ノート操作を案内します。
- 関連リンクのボタンを「線でつなぐ」に改名。相手のノートを選んで押すと、本文の現在の行の下にリンクが入り、解析後に線が出ます。
- 選択中ノートの白い丸印を削除。背景色による選択表示は維持します。

検証：Editor/PlayerのC#コンパイル成功。Mono簡易ランナーで192件成功、0失敗。プロジェクト間の切替時にパス・一覧・現在ノートが一致すること、閉じた後の未選択、関連リンクから線の生成、保存失敗時に閉じないことを含みます。
