# ノート順・新規ボタン・読み込み表示・戻る操作

- ノート一覧を数字に対応した自然順へ変更。同じフォルダ内では「無題のノート」→「無題のノート 2」→「無題のノート 3」→「無題のノート 10」の順になります。フォルダ優先の既存動作は維持します。
- 保存先未選択時の「保存先を選んで書く」を削除し、新規ボタン自体を非表示にしました。保存先を開くと「＋ 新しいノート」を表示します。空の保存先でも最初のノートを作成できます。
- 主編集欄・分割欄の取り消しボタンを「↶ 戻る」へ変更し、文字入力・書式変更を取り消す操作であることをツールチップに明記。Ctrl+Zとやり直しも維持しています。
- Undo履歴をノート単位に保持。別ノートへ移動して戻っても履歴を再利用します。元本文が一致しない外部更新の場合は古い履歴を破棄し、誤った上書きを防止。保存先開閉・名前変更・削除ではキャッシュをリセットします。

## 動画の確認
添付動画をフレームに分解して確認しました。約12.97〜13.23秒付近に、UIの背後の3D背景（空と地平線）が透けるフレームがあります。一般的な文字描画崩れとは異なる、画面全体が透ける状態です。
読み込み操作でroot.SetEnabled(false)にした際のテーマの無効状態表示が原因の可能性が高いため、アプリのルートにinline opacity=1と.cartowords:disabled opacity=1を設定し、読み込み中も背景が不透明になるよう修正しました。操作中の入力停止と読み込み中のカバーは維持します。
修正後のUnity実機で同じ操作をして動画比較する検証はまだ行っていません。添付動画で症状を確認したことと、修正後の再現テストは区別しています。
