# 関連ノートの切替・選択色・読み込み画面

- 関連ノートのチェック済み項目を押すと解除、未接続の項目を押すと接続を要求するよう変更。チェック表示は引き続き実際に反映されたマップの線を基準にします。
- 解除時は対象2ノートの両方向のリンクを調べ、コード内や別ノートへのリンクを除外して、対象リンク文字列だけを降順に削除。周囲の本文・理由文・来歴ラベルは保持します。書式操作として審査経由で適用します。
- 選択色を薄い水色 rgba(199,239,244,0.42) に変更。
- ファイル選択前から読み込み完了後の短い間、背景が不透明な「保存先を読み込んでいます…」画面を表示。切り替え途中の編集欄・地図を隠し、描画更新後に画面を戻します。
- ファイル選択ダイアログは既存の遅延実行を維持し、キャンセル・読み込み失敗時も読み込み画面を閉じます。エラーは通常画面で表示します。

検証：Unity6000.3.24f1参照DLLによるEditor/Player構成のC#コンパイル成功。Mono簡易ランナーで220件成功、0失敗。追加6件はリンク範囲特定（コード・曖昧名・CRLF・見出し指定等）、双方向解除、本文・typed来歴保持です。
実際の画面乱れの完全解消、選択色の見た目、メニュー操作はUnity実機では未確認です。表示切替途中を隠す対策であり、GPU/Unity描画の原因を特定したものではありません。
