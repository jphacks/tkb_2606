# 感情語辞書 初版(下書き)

確認用の一覧。実体は [`DefaultEmotionWords.cs`](../../Assets/Cartograph/Analysis/Emotion/DefaultEmotionWords.cs)(`EmotionLexicon.Default`)。
分類は筆者の判断で、**チームでの見直しが必要**。仕様書では「数十〜数百語を自作」とあるが、初版は感情語 67 語(喜 15・怒 17・哀 20・楽 15)と除外語 6 語。

## 仕組みのおさらい

- 本文の typed の文字から、**最長一致**で探す。形態素解析はしない。
- 語は 2 文字以上。い形容詞は**語幹**で登録する(例: `嬉し` で 嬉しい・嬉しく・嬉しかった に当たる)。
- 語の直後が「ない」「ません」「くない」「じゃない」などで始まれば、枯れた花。
- 同じ文の同じ語は 1 輪。見出し行とコードブロックの中は対象外。
- **除外語**: 語幹が別の語の一部に当たる(例: 「音楽します」の `楽し`)ときに、その別の語を先に読み飛ばす。typed かどうかは問わない。

## 今回の整理で直した誤検出

| 以前の語 | 問題 | 対応 |
| --- | --- | --- |
| `切な` | 「大切な」「親切な」「適切な」に当たる | `切ない`・`切なく`・`切なさ` に分けた |
| `つら` | 「つらら」「つらなる」に当たる | `つらい`・`つらく`・`つらさ` に分けた |
| `空し` | 「上空しか」に当たる | `空しい`・`空しく` に分けた |
| `ほっと` | 「ほっとく」(放っておく)に当たる | `ほっとし` にした |
| `楽し` | 「音楽します」に当たる | 除外語 `音楽`・`娯楽`・`洋楽`・`邦楽` を足した |
| `不安` | 「不安定」「不安全」に当たる | 除外語 `不安定`・`不安全` を足した |

## 見直してほしい点

1. **分類の境界**: 筆者の判断で、次のように分けた。
   - `悔し`・`不安`・`恐怖` は哀。`悔し` は怒にも近く、`不安`・`恐怖` は 4 種にない「恐れ」に近いが、4 種に収めるため哀にした。
   - `感謝`・`安心`・`満足` は喜。`癒され`・`気楽`・`のんびり` は楽。
2. **残っている誤検出の可能性**: 辞書の語が別の語の一部に当たる例は、まだ見つかっていないものがありうる。見つけたら除外語に足す。
   - 例: `感動` は「感動詞」(文法用語)、`孤独` は「孤独死」のような語、`満足` は「不満足」にも当たる。
3. **否定の誤り**: 「悲しくないはず」のような文は枯れた花になる。「楽しくないわけではない」(二重否定)も枯れる。文字列の一致だけで判定している(仕様書の「仮」)。
4. **足りない語**: 数十〜数百語の目標に対して、初版は感情語 67 語(喜 15・怒 17・哀 20・楽 15)と除外語 6 語。足りなければ公開辞書を足す(その時に利用条件を確認する)。
5. **形式**: CSV は `語,分類` の仮。`settings.json` への保存と、利用者が語を足せるようにするかは未決。
