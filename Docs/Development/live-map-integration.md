## Unityで試す手順
1. 再生停止→コンパイル完了→再生。保存先を開く。
2. ノートに大見出しを作り本文を入力。確定編集から約500ms後＋解析時間でマップが更新されます。
3. もう1件ノートを作り、[[相手のノート名]]を書いて道がつながるか確認。
4. 直接「嬉しい」「悲しい」などを入力して花を確認。履歴のない既存本文はunknown扱いなので、既存の感情語だけでは花が出ない場合があります。
5. マップの見出しをダブルクリックして該当行を分割欄に開く。
6. ノート横⋯→削除…→確認。右クリックからも開けます。
