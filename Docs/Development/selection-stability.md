# 文字選択の表示・復元の安定化

- 主編集欄と分割欄の見えないMarkdown用TextFieldへ毎フレームSelectRangeしていた処理を削除。書式ボタン用の元本文選択位置は専用の値として保持し、実際の選択フィールドへ干渉させません。
- ネイティブTextFieldのselectAllOnFocus/selectAllOnMouseUpを無効化し、最初のクリック・ドラッグ時の自動全選択との競合を避けました。
- 段落再構築後の遅延カーソル復元に、入力世代・ノート・本文・フォーカス・ドラッグ中のガードを追加。ユーザーの新しい選択や別ペイン・ダイアログへの移動を優先します。
- 他ペインから本文が変わった際は選択範囲を差分に合わせて移動し、無条件に一点へ折り畳まないよう変更。
- 選択背景色を濃い青に変更し、本文とのコントラストを強めました。
