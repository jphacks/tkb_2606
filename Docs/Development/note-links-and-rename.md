# ノート名前変更・未選択表示・関連リンク

## 操作
- ノート横「⋯」または右クリック→「名前を変更…」→新しい名前→「変更する」。現在表示していないノートにも使えます。上のタイトルを編集する既存の操作も継続します。
- 保存先はフォルダを選びます。起動時や閉じた後は「まだノートが開かれていません」と表示。保存先を開くと一覧をロードし、最初のノートを表示します。
- 空の保存先を開くだけでは無題ノートを自動作成しません。「新しいノート」で作成します。「保存先を選んで書く」から始めた場合は空の保存先に1件作成します。
- 「町とノート」の見出しを削除。
- 本文上の「関連ノート」で相手を選び「リンクを追加」。カーソルがある行の下に[[相手のノート]]を挿入し、既存解析が現在の見出しから相手ノートの最初の拠点へ線を作ります。通常は確定編集後500msと解析時間で更新します。

## 接続仕様
- 関連リンクは既存のMarkdownリンク構文を使い、別の保存形式や解析APIは追加していません。書式操作として挿入するので来歴はunknownですが、リンク解決の対象になります。
- フォルダ内のノートは相対パスで指定し、他フォルダの同名ノートと区別します。
- 解析側で特定できないルートの同名ノートや、#・角括弧入りの名前は誤った線を作らないよう操作を止め、名前変更を案内します。解析構文自体は変更していません。
- 名前変更は既存Bridge.RenameDocumentを使用。本文・履歴は既存処理で移動します。本文中の既存リンクの自動書き換えは行いません。変更後にリンク切れになった場合は関連ノートを選び直して修正できます。
- プロジェクト未選択でも操作エラーを表示できるよう、エラー欄を編集本文とは独立させました。
