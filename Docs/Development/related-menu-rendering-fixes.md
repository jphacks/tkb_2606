# 関連ノートメニューと表示の修正

- 関連ノートのDropdownFieldをボタン＋GenericDropdownMenuへ変更。メニューには実ノートだけを表示し、「＋関連ノートを選んでつなぐ」という仮項目は削除しました。
- チェックは受理済みMapSnapshotの実際の道を基準にします。現在ノートとの送信・受信両方向のノート間接続を集計し、自動の見出し親子線は対象外。解析待ちの選択操作だけではチェックしません。
- 接続済み項目を選んでも重複追加しません。本文内にも既存の同じリンクがある場合は再挿入しません。メニューは接続状態の表示と接続追加用で、チェックを外して切断する操作は今回追加していません。
- [[ノート]]だけの行は保存と解析用に保持し、主編集欄・分割編集欄では表示しません。文字数からも除外します。通常の文章中のインラインリンクは本文として残します。
- キーボード移動時には非表示リンク行を飛ばし、Backspace/Deleteで隣接するリンク行を通常段落へ結合しないようにしました。
- ファイル選択ダイアログをUIクリックイベントの最中に直接開かず、Unity EditorのdelayCallで開くよう変更。再クリックを抑止し、ダイアログ終了・プロジェクト表示更新・アプリのフォーカス復帰後にUIの再描画を予約します。

画面乱れの調査：Unityログには描画・フォントの例外は見つからず、原因の断定はできていません。ダイアログ前後の描画更新を安定させる対策です。症状の完全解消を実機で確認したものではありません。

検証：Unity6000.3.24f1参照DLLでEditor・Player構成のC#コンパイル成功。Mono簡易ランナーで214件成功、0失敗。追加3件はリンク行の表示判定・文字数、重複防止、実際の道に基づく接続状態です。
Unity画面でのメニューと描画乱れの再現確認は未実施です。元データの削除や新しい保存形式の追加はしていません。
