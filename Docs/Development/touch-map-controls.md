# タッチ拡大・縮小とプロジェクト操作の整理

- マップのタッチ操作を追加。1本指で移動、2本指の距離で拡大縮小、2本指の中心の移動でパンします。拡大の中心は2本指の中点に追従します。
- ピンチ中やその直後の指上げを拠点選択と誤認しないようにし、キャンセル・キャプチャ喪失・画面から外れた際に状態を破棄します。指が重なった時の0除算を避け、既存の倍率制限を使います。
- マウスのドラッグ・ホイール・＋／−ボタンは継続。
- プロジェクト欄の「開いています」「未選択」などの補助ラベルを削除。空欄時の「ファイルが選択されていません」は維持します。
- 操作ボタンを左から「ファイルを選択」→「閉じる」だけに整理。「開く」「フォルダを選択」は削除しました。
- Unity Editorでは「ファイルを選択」で保存先フォルダの選択ダイアログを開き、確定したフォルダを開きます。保存先の構造は従来通りフォルダ単位です。
- ビルド済みPlayerにはまだネイティブのフォルダ選択UIが同梱されていないため、パス入力後に「ファイルを選択」を押す既存方式の代替経路を維持しています。

検証：Unity6000.3.24f1参照DLLでEditor・Player用C#コンパイル成功。Mono簡易ランナーで196件成功、0失敗。追加4件はピンチ中心・倍率、2本指移動から1本指への継続、タップ／移動／キャンセル判定、ゼロ距離と倍率制限です。
タッチスクリーンやトラックパッドの実機では未確認。今回追加したのはUI Toolkitのtouchポインターによるピンチです。OSがタッチパッドのピンチをtouchイベントとして渡すかは機種依存で、wheelとして届く場合は既存のwheel操作が使われます。
